About Yondr

Yondr was built using standard web technologies by me, Rylee Corradini. It's a Progressive Web App, meaning you can install it directly to your tablet/phone screen/desktop like a regular app, and it will behave more or less the same as one.

(Side note: I've made a bunch of these at this point; you can see the full list here if you're interested.)

Have you ever found yourself trying to decide between two or more living situations / job options, and had a hard time comparing them in a way that helped you to see things clearly? Yondr was built for you!

Starting a project in Yondr is simple: create a "crossroad" (i.e. a decision point) and add different job/relocation options as "paths" to compare. Several jobs can share a location, each with its own work policy, listing link, status, and dated notes. Choose a location and currency for each path. Enter a salary range while a job is still a possibility, then add a concrete salary and any bonuses when they are known. You can set up your user settings with your current location, cost of living spend, citizenship, tax filing status, and any fixed pre-tax expenses (like insurance or support payments). Yondr will then help you compare your options at a glance: compensation, taxes, estimated cost of living based on location indices, and the all-important Bottom Line: how much money you'll actually have left over each year after taxes and living expenses.

Most art assets are from SVG Repo or Pixabay; placeholder animation was generated using SVGBackgrounds.com. All were tweaked by me, because SVG is rad that way.
